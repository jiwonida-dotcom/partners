# 제휴 채널 다이렉트 연동 및 CMS 정책 관리

제휴 채널(모요)에서 구성된 단말·요금제 조합을 프로모션 정책 코드(`promoNo`)로 전달받아
유모바일 가입 퍼널에 승계하고, 진입 채널을 구입처로 귀속시키는 연동 체계의 기획 산출물입니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 랜딩 페이지 |
| `plan.html` | 기획서 (시스템 정의·설계 / 기능 정의 / 화면 설계 / 이슈 트래킹) |
| `prototype.html` | 동작 프로토타입 (CMS 등록 + Front 진입 시뮬레이터) |

외부 의존성이 없는 정적 HTML입니다. 빌드 과정이 필요하지 않습니다.

## GitHub Pages 배포

```bash
git init
git add .
git commit -m "제휴 채널 연동 기획 산출물"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

푸시 후 저장소 **Settings → Pages** 에서
- Source: `Deploy from a branch`
- Branch: `main` / `/ (root)`

저장하면 1~2분 뒤 아래 주소로 공개됩니다.

```
https://<계정>.github.io/<저장소>/
https://<계정>.github.io/<저장소>/plan.html
https://<계정>.github.io/<저장소>/prototype.html
```

> 사내 공유만 필요하면 저장소를 Private으로 두고 GitHub Pages 대신 파일을 직접 전달해도 됩니다.
> Public 저장소로 배포할 경우 문서에 포함된 URL·정책 정보가 외부에 노출되므로 사전 확인이 필요합니다.

## 프로토타입 사용법

**CMS 정책 등록** — 유효 코드로 검증을 통과해야 저장됩니다.

| 항목 | 유효 코드 |
|---|---|
| 모델 | `PH2508` (갤럭시 S25 울트라) / `PH2401` |
| 색상 | `CL07` (티타늄 블랙) / `CL02` |
| 요금제 | `5GP100` (5G 프리미어 에센셜) / `5GS200` |

**Front 시뮬레이터** — 5개 시나리오 버튼으로 진입을 재현합니다.

| 시나리오 | 결과 |
|---|---|
| 정상 진입 | 확인 페이지 렌더 → 신청서 작성하기 → 세션 승계 후 가입신청서 |
| EX-01 정책코드 없음 | Alert 없이 휴대폰 목록 이동, 판매처 유모바일 전환 |
| EX-02 일부 색상 품절 | Alert 후 휴대폰 상세 이동, 구입처 유지 |
| EX-03 전체 품절 | Alert 후 휴대폰 목록 이동, 구입처 유지 |
| EX-04 요금제 미사용 | Alert 후 휴대폰 상세 이동, 구입처 유지 |

데이터는 브라우저 메모리에만 저장되며 새로고침 시 초기화됩니다.
