제휴 채널 다이렉트 연동 및 CMS 정책 관리

제휴 채널에서 구성된 단말·요금제 조합을 프로모션 정책 코드로 전달받아 가입 퍼널에 승계하고, 진입 채널을 구입처로 귀속시키는 연동 체계입니다.

문서 기준일 2026-07-28 설계 v1.4 · 기능정의 v2.4 · WF v2.4 확정 8건 미확정 2건 · 개발 협의 6건

추진 개요

한 줄 정의제휴 채널(초기 구축: 모요)의 이벤트 상세 페이지에서 구성된 단말(색상 지정) + 요금제 조합을 프로모션 정책 코드(promoNo)로 식별해, 유모바일 가입 퍼널에 구매 정보를 승계하고 진입 채널을 구입처로 귀속시킵니다.
목표 1

퍼널 단축

단말 상세페이지의 옵션 재선택 단계를 스킵. 퍼널 스텝 축소를 통한 전환율 개선

목표 2

채널 어트리뷰션

정책 코드 단위로 구입처를 귀속. 채널별 성과 측정 및 정산 근거 확보

목표 3

운영 자율성

CMS 정책 등록만으로 프로모션 운영. 배포 의존성 제거

To-Be 진입 아키텍처

검증 게이트 위치검증과 예외 처리는 정책 확인 페이지 진입 시점에 전량 선행됩니다. 예외 발생 시 가입신청서에 도달하지 않으므로, 유효하지 않은 구성이 퍼널 하류로 유입되지 않습니다.

개발 대상 범위

Layer대상구분범위
Front정책 확인 페이지신규파라미터 검증, 예외 폴백, read-only 렌더, 세션 적재
Front가입신청서기존세션 복원 및 구매정보 세팅 (화면 규격 변경 없음)
Front단말 목록 / 상세기존예외 폴백 목적지
Back정책/상품 API신규정책 조회, 유효성 검증, 재고·요금제 상태 조회
BackCMS 제휴 상품 관리신규정책 리스트·등록·수정 (PC 웹 전용)

설계 원칙

Read-only 렌더 원칙

정책 지정 값은 선택 컨트롤(radio/select) 없이 텍스트·배지로만 렌더합니다. 미선택 옵션은 DOM에서 제외해 조작 가능 오인을 차단합니다. 변경은 상담 프로세스에서 처리합니다.

어트리뷰션 보전 원칙

정책 자체가 무효(EX-01)일 때만 구입처를 유모바일로 전환합니다. 정책은 유효하나 재고·요금제 사유로 차단된 경우(EX-02~04)는 구입처 귀속을 유지합니다.

혜택 비적용 원칙

정책 코드 진입에 따른 추가 혜택은 없습니다. 단말 상세페이지 전용 혜택인 U폰 캐시 할인과 쓰던 폰 보상 판매는 노출·적용 대상에서 제외합니다.

2. 파라미터 검증 시퀀스

정책 확인 페이지 진입 시점에 서버 검증으로 수행합니다. 선순위 STEP에서 차단되면 후순위 검증은 실행하지 않습니다.

STEP 1
파라미터 파싱
promoNo 존재 여부 및 형식 검증 (영문·숫자 8자리)
실패 → EX-01
STEP 2
정책 존재 검증
promoNo를 Key로 정책 레코드 조회
실패 → EX-01
STEP 3
사용 여부 검증
use_yn = 'Y' 여부 확인
실패 → EX-01
STEP 4
유효 기간 검증
start_dt ≤ now ≤ end_dt
실패 → EX-01
STEP 5
단말 재고 검증
model_cd + color_cd 재고 조회, 동일 모델 타 색상 재고 유무 판별
색상 품절 → EX-02
전 색상 품절 → EX-03
STEP 6
요금제 상태 검증
요금제 속성 "사용자 노출 활성화" = 사용 여부 확인
실패 → EX-04
STEP 7
렌더
정책 지정 값 read-only 렌더, 검증 결과를 서버 세션에 적재
—
처리 원칙STEP 1~4 실패는 사유를 구분하지 않고 모두 EX-01로 동일 처리합니다. STEP 5~6 실패 시에는 구입처를 정책 지정 값으로 유지해 어트리뷰션을 보전합니다. 우선순위는 EX-01 > EX-02/03 > EX-04 입니다.
